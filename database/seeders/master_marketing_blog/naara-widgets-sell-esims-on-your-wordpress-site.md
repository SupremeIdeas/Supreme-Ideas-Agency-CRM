If you run a travel blog, a tour company or a community site, your readers already ask where to get data abroad. **Naara Widgets** let you answer with a catalogue on your own page.

## The pieces

- **Widget keys.** A key identifies your site. You can add several and switch one off at any time.
- **The embed.** A short snippet that shows the plans, with real logos and details.
- **Hosted checkout.** The payment page is the only page the app allows to be framed, so your visitors pay in a place built for it.
- **WordPress plugin.** If you use WordPress, the plugin adds the catalogue without touching code.

## What visitors see

A clean list of plans, the exact data and validity, and a checkout that supports guests, so nobody has to create an account before buying.

## What you see

Orders and events are tracked for each key. A premium analytics view shows how your widget performs. Whether the widget is free or paid is set by the platform admin.

## Safe by design

Keys are scoped to your account. The checkout page is separate from the app, and the API rejects anything that is not signed or not yours.

## Getting started

1. Create a widget key in your dashboard.
2. Paste the snippet (or install the plugin).
3. Place an order yourself in test mode.
4. Watch it appear in your orders.

If you build products rather than pages, pair this with the developer API and signed webhooks described in our developer guide.

## Questions people ask

**Do I earn on orders?**
Widget terms, including any merchant discount, are set by the platform. Your dashboard shows the terms for your key.

**What if a visitor's payment fails?**
The hosted checkout shows the failure and nothing is delivered. A charge that does not result in delivery is refunded.

**Can I limit which site uses my key?**
Yes. Keys are scoped to your account and can be switched off at any time.
