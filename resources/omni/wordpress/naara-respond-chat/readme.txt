Add your Naara Respond website chat to every page. Messages arrive in your Naara inbox next to WhatsApp, Instagram, Messenger, Telegram, SMS and email.

== Description ==
The chat bubble loads from your own Naara address. The plugin stores only your Naara address and your chat's public site key. No secrets, no visitor data on your WordPress server.

== Installation ==
1. Download the plugin from Naara: Business, Channels, Website chat, Download WordPress plugin. It arrives already set up.
2. In WordPress open Plugins, Add New, Upload Plugin, choose the zip, Activate.
3. In Naara open Channels, Website chat, and make sure your WordPress site address is in the allowed websites list.
4. Visit your site: the chat bubble is there. Settings, Naara Chat lets you hide it for yourself or switch it off.
